# Iven Corstal — Der stille Kontakt (Kapitel 8, Spoiler-Dokument)

**Rolle:** Empfänger von Cassians Geheimauftrag in Kapitel 8 (`../chapters/08-der-geheimauftrag/`) — die Person (bzw. der Ort/Kontaktpunkt), an die die Gruppe eine versiegelte Nachricht/ein Objekt übergibt, ohne zu wissen, warum es wichtig ist.

**Auftreten:** Zurückhaltend, unauffällig, wirkt eher wie ein kleiner Händler/Schreiber/Lagerverwalter als wie jemand von Bedeutung — bewusst so gestaltet, dass die Gruppe ihn nicht für wichtig hält.

**Verhalten:** Nimmt die Übergabe knapp, fast routiniert entgegen — keine Dramatik, keine auffällige Reaktion. Stellt höchstens eine einzige, beiläufige Prüf-/Gegenfrage (ein Codewort, ein Detail, das nur der wahre Bote wüsste), um die Übergabe zu bestätigen — genug, damit die Spielrunde merkt, dass hier mehr dahintersteckt, ohne dass es erklärt wird.

**Geheimnis (SL-only):** Selbst Mitglied im Grauen Bund (siehe `secret-society.md`). Sein Kontor/Zimmer enthält ein graues Wachssiegel (auf einem Brief, einem Dokument o. Ä.) — der bisher deutlichste Bund-Clue der Kampagne, sofern die Gruppe genau hinsieht. Wird nie erklärt; falls die Gruppe fragt, bleibt er schlicht ausweichend ("Nur Geschäftskram").

**Verhältnis zu Cassian:** Für die Gruppe unklar, ob Cassian und Iven sich gut kennen oder es eine rein geschäftliche Verbindung ist — beide sind über den Bund verbunden, was aber nirgends offen ausgesprochen wird.
