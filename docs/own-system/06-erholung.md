# Erholung

## Kurzrast

Ein kurzes **"Luftholen", 5–10 Minuten**: heilt **nur HP vollständig**, sonst nichts. **Keine** zusätzliche Mana-Regeneration über die passive Regel hinaus (siehe [05-magie-und-uebernatuerliches.md](05-magie-und-uebernatuerliches.md) — Mana füllt sich ohnehin schon von selbst über Zeit außerhalb des Kampfes) und **keine** Wirkung auf schwere Verletzungen/Wunden (dafür ist ein Heiler nötig, siehe [04-tod-und-konsequenzen.md](04-tod-und-konsequenzen.md)). Eine Langrast füllt den Mana-Pool garantiert komplett auf, unabhängig vom passiven Regen.

## Langrast

Bedingungen: **sicherer Ort**, Lager aufschlagen, "übernachten" (eine Nacht). Repariert **alles außer Wunden** (dafür weiterhin ein Heiler nötig).

**Kein Rasten über mehrere Tage** → Mali auf Proben/Handlungen (Erschöpfung durch fehlende Erholung), gestaffelt:

| Tage ohne Langrast | Effekt |
|---|---|
| 1 Tag | kein Malus |
| 2 Tage | Bane auf alle körperlich anspruchsvollen Proben |
| 3 Tage | zusätzlich −2 auf Angriffswürfe |
| 4+ Tage | zusätzlich maximale HP sinkt um 25% (aufgerundet), bis zur nächsten Langrast |

Eine einzige Langrast setzt die Stufe komplett zurück auf 0.

## Nahrung/Wasser/Schlaf

Wird **grob getrackt**, kein strenges Hunger-/Durst-System im Detail — nur als grobe Orientierung vorhanden.

## Langzeitverletzungen

Siehe [04-tod-und-konsequenzen.md](04-tod-und-konsequenzen.md) — Wunden heilen nur mit Heiler, Ausgang folgt der 80/10/10-Tabelle dort.

## Erholung von psychischem Stress

Entfällt — **kein Sanity-/Stress-System** im Spiel.
