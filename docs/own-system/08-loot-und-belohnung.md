# Loot & Belohnung

## Loot Tables

Ein Wurf pro Encounter/Kreatur (1W20), gestaffelt nach grober Wahrscheinlichkeit — verweist auf die Listen in [15-katalog-items.md](15-katalog-items.md):

| Wurf | Ergebnis |
|---|---|
| 1–6 | nichts Nennenswertes |
| 7–12 | ein paar Münzen (1W6 × 5 Kupfer, skaliert grob mit Bedrohungsstufe der Kreatur) |
| 13–16 | ein Alltagsgegenstand/allgemeiner Loot-Fund |
| 17–18 | ein Verbrauchsgegenstand (Consumable) |
| 19 | ein mundanes Ausrüstungsteil (Waffe/Rüstung, Common/Uncommon) |
| 20 | Chance auf ein magisches Item — zusätzlicher Wurf auf die Rarity-Tabelle (siehe 15-katalog-items.md), stark gewichtet Richtung Rare statt Legendary |

Bei Gruppen-Encountern (mehrere Kreaturen) wird **einmal pro Encounter**, nicht pro Kreatur gewürfelt, um die Tabelle nicht zu inflationieren.

## Magische Items

Bereits über die Rarity-Regel abgedeckt (siehe [07-ausruestung-und-oekonomie.md](07-ausruestung-und-oekonomie.md)) — ab Rare/Legendary können Items verzaubert sein bzw. Zauber enthalten.

## Nicht-materielle Belohnungen

Kontakte/Reputation werden **rein über Erzählung** gehandhabt, keine eigene Mechanik — mit einer Ausnahme: bei **wichtigen NPCs** wird notiert, was sie von der Gruppe halten (z. B. relevant für Rabatte), siehe [09-bestiary-und-npcs.md](09-bestiary-und-npcs.md).

## Zufallsgenerierung vs. handkuratiert

**80% gewürfelt** über die Loot-Tabellen. Der Rest sind gezielt platzierte Fundstücke — vor allem legendäre/seltene Items werden gerne bewusst gesetzt statt ausgewürfelt.
