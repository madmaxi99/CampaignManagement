# DM-Bereich + Wiki (Kompendium) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Homepage bekommt einen "DungeonMaster"-Button → `/dm` Zwischenseite → `/dm/wiki` Kompendium mit 5 Kategorien (Bestiarium, Items, Zauberbücher, Relikte, Bücher), jede mit eigener SQLite-Tabelle, Liste, Anlegen- und Bearbeiten-Formular.

**Architecture:** Eine echte Tabelle pro Kategorie, aber generisch angesteuert über eine PHP-Kategorie-Konfiguration (`WikiCategories`) + ein generisches PDO-Repository (`WikiRepository`) + generische Twig-Templates (`wiki/list.twig`, `wiki/form.twig`). Ein generischer Satz Slim-Routen (`/dm/wiki/{category}/...`) bedient alle 5 Kategorien, statt pro Kategorie eigene Routen/Controller zu duplizieren.

**Tech Stack:** PHP 8.3, Slim 4, Twig (`slim/twig-view`), PDO/SQLite. Kein neues Composer-Paket nötig.

**Spec:** `docs/superpowers/specs/2026-09-09-dm-wiki-design.md`

## Global Constraints

- **Keine `git commit`-Schritte.** Das Projekt ist aktuell kein Git-Repository, und der Nutzer möchte Commits ausschließlich auf explizite Anforderung — gilt projektübergreifend, auch in Subagent-/Workflow-Kontexten. Jeder Task endet mit einem Verifikationsschritt statt einem Commit-Schritt.
- **Kein neues Test-Framework.** Das Projekt hat keine PHPUnit-Infrastruktur. Verifikation läuft wie beim bestehenden Hello-World-Smoketest über `curl` gegen den laufenden `nginx`/`php-fpm`-Container (Container laufen bereits über `provisioning/docker-compose.yml`, Port 8090).
- **Mehrzeilige SQL-Strings als Heredoc** (`<<<SQL ... SQL;`), kurze Einzeiler als normale Strings.
- **Tabellen-/Spaltennamen kommen ausschließlich aus `WikiCategories::CATEGORIES`**, nie direkt aus der URL in SQL. Das `{category}`-Routensegment wird in JEDEM Handler zuerst gegen `WikiCategories::find()` geprüft (404 bei unbekanntem Slug), bevor der zugehörige Tabellenname verwendet wird.
- Bezeichner/Code auf Englisch, UI-Text/Kommentare auf Deutsch (wie im bestehenden Code).
- Alle neuen PHP-Klassen unter `backend/src/`, per `require` in `backend/public/index.php` eingebunden (kein Composer-Autoload-Setup vorhanden, wird für diesen Umfang nicht eingeführt).

### Task 2: Generisches Repository (`WikiRepository`)

**Files:**
- Create: `backend/src/WikiRepository.php`

**Interfaces:**
- Consumes: `PDO` Instanz (wie bereits in `public/index.php` erzeugt), Spalten-Array im Format aus Task 1 (`WikiCategories::CATEGORIES[...]['columns']`).
- Produces: `WikiRepository::__construct(PDO $db)`, `ensureTable(string $table, array $columns): void`, `all(string $table): array`, `find(string $table, int $id): ?array`, `insert(string $table, array $columns, array $data): void`, `update(string $table, array $columns, int $id, array $data): void`.

- [ ] **Step 1: Datei erstellen**

```php
<?php

declare(strict_types=1);

final class WikiRepository
{
    public function __construct(private PDO $db)
    {
    }

    public function ensureTable(string $table, array $columns): void
    {
        $columnDefs = array_map(
            static fn (array $col): string => sprintf(
                '%s %s',
                $col['name'],
                $col['type'] === 'number' ? 'INTEGER' : 'TEXT'
            ),
            $columns
        );

        $sql = sprintf(
            'CREATE TABLE IF NOT EXISTS %s (id INTEGER PRIMARY KEY AUTOINCREMENT, %s, created_at TEXT NOT NULL, updated_at TEXT NOT NULL)',
            $table,
            implode(', ', $columnDefs)
        );

        $this->db->exec($sql);
    }

    public function all(string $table): array
    {
        $stmt = $this->db->query(sprintf('SELECT * FROM %s ORDER BY id DESC', $table));

        return $stmt->fetchAll(PDO::FETCH_ASSOC);
    }

    public function find(string $table, int $id): ?array
    {
        $stmt = $this->db->prepare(sprintf('SELECT * FROM %s WHERE id = :id', $table));
        $stmt->execute(['id' => $id]);
        $row = $stmt->fetch(PDO::FETCH_ASSOC);

        return $row === false ? null : $row;
    }

    public function insert(string $table, array $columns, array $data): void
    {
        $names = array_map(static fn (array $c): string => $c['name'], $columns);
        $placeholders = array_map(static fn (string $n): string => ':' . $n, $names);
        $now = (new DateTimeImmutable())->format('Y-m-d H:i:s');

        $sql = sprintf(
            'INSERT INTO %s (%s, created_at, updated_at) VALUES (%s, :created_at, :updated_at)',
            $table,
            implode(', ', $names),
            implode(', ', $placeholders)
        );

        $params = $this->normalizeParams($columns, $data);
        $params['created_at'] = $now;
        $params['updated_at'] = $now;

        $this->db->prepare($sql)->execute($params);
    }

    public function update(string $table, array $columns, int $id, array $data): void
    {
        $names = array_map(static fn (array $c): string => $c['name'], $columns);
        $assignments = array_map(static fn (string $n): string => sprintf('%s = :%s', $n, $n), $names);

        $sql = sprintf(
            'UPDATE %s SET %s, updated_at = :updated_at WHERE id = :id',
            $table,
            implode(', ', $assignments)
        );

        $params = $this->normalizeParams($columns, $data);
        $params['updated_at'] = (new DateTimeImmutable())->format('Y-m-d H:i:s');
        $params['id'] = $id;

        $this->db->prepare($sql)->execute($params);
    }

    private function normalizeParams(array $columns, array $data): array
    {
        $params = [];

        foreach ($columns as $col) {
            $name = $col['name'];
            $raw = trim((string) ($data[$name] ?? ''));

            if ($col['type'] === 'number') {
                $params[$name] = $raw === '' ? null : (int) $raw;
            } else {
                $params[$name] = $raw;
            }
        }

        return $params;
    }
}
```

$app->get('/dm/wiki/{category}/new', function ($request, $response, array $args) use ($twig) {

        return $response->withStatus(404);

    if ($categoryConfig === null) {
        return $response->withStatus(404);
    }

    $primary = $categoryConfig['columns'][0];

    if (trim((string) ($data[$primary['name']] ?? '')) === '') {
